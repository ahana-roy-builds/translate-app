# Offline Hindi recognition benchmark

This opt-in iPhone test measures the original 13 synthetic Hindi recordings and six new clips with different rates, including two mixed Hindi–English prompts. Both recognizers receive the same audio and the same Apple translation engine translates their transcripts. The test records model load time, per-turn latency, process high-water memory, sampled thermal state and two immediate English replies. The new prompts, expected messages and audio checksums are in `held-out.json`. The energy counters sample CPU energy attributed to the test host during Whisper decoding and the streamed Apple control. Whole-device battery use, GPU energy and Apple’s separate recognition service require separate measurement. [Apple kernel accounting](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/kern/task.c#L6387-L6403)

1. Build the iOS Debug test host with the LocalLingo scheme using `build-for-testing`. Build a test adapter with `build-adapter.sh <whisper.cpp-source> <scratch-build-dir> <output-dylib>`. The matched experiment uses whisper.cpp v1.9.5.
2. Stage the 16 WAVs in this directory’s `fixtures` folder and the three Hindi WAVs from `evaluation/fixtures/continuous-speech` in a temporary folder. Name the latter `matrix-0.wav` through `matrix-2.wav`. Place the previously verified Q5 model there as `model.bin`. Its SHA-256 is `394221709cd5ad1f40c46e6031ca61bce88931e6e088c188294c6d5a55ffa7e2`. [Model](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-large-v3-turbo-q5_0.bin)
3. Use `xcrun devicectl device copy to` with the Debug app’s data container and destination `Library/Caches/hindi-model-trial`. Run `python3 evaluation/hindi-model-trial/run.py <xctestrun> <adapter-dylib> <device-UDID> <signing-identity> <result.xcresult>`. The runner signs a disposable copy of the Debug host and enables the benchmark for that one test. Search the test output for `HINDI_TRIAL`. Add `--clean-up` on the last run to remove the staged model and the nineteen benchmark WAVs from the Debug app cache.
